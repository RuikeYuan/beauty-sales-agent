# 异议回应

输入：客户顾虑原话、需求和报价结果。输出：准确复述顾虑、可验证说明、低压力下一步。

“贵”可能指今天新增支出、长期总预算或担心一直加项。已有证据就直接回应；不清楚时只问最关键的区别。不要一听贵就降价或推卡。

| 顾虑 | 回应依据 |
|---|---|
| 怕没有效果 | 说明购买的是基础服务；本人感受可以记录，不能保证变化；照片条件不同不能直接证明改善 |
| 怕用不完 | 比较确定次数、预付款、有效期和退款手续；需要时推荐单次 |
| 怕后续加钱 | 以项目内容、费用、追加项目须单独确认说明；不能编造终身价格保证 |
| 想再考虑 | 接受；客户愿意才澄清一次，不连续逼问 |
| 要折扣/赠品/好评换价 | 依据已确认活动；没有则不承诺，不把真实评价与购买绑定 |
| 问同行差异 | 比较可核实的服务、预约、费用与记录，不评价未见过的服务 |

最多给出 1–2 个当前适合的选择，包含暂不购买。客户明确拒绝后不再推进其他套餐。报价和条款仍以 [门店规则](../../references/门店规则.md) 为准。
