# 教学门店规则 v1

仅用于本包虚构案例；不是现实门店政策、医疗建议或法律结论。来源见 [素材蒸馏](素材蒸馏.md)。

| 项目 | 规则 | 来源 |
|---|---|---|
| 服务 | 非侵入式基础清洁、保湿护理；不提供注射、激光、治疗 | 01、05 |
| 首次体验 | 79 元一次，约 35 分钟；须核实首次资格 | 01、05 |
| 常规单次 | 240 元，约 40 分钟 | 01、03 |
| 四次卡 | 880 元，四个月有效，每次核销 220 元 | 01–05 |
| 内容 | 三种价格的基础项目相同；具体用品以服务单为准 | 01、05 |
| 未用次数退款 | 每次按 220 元申请退回，不按 240 元倒扣；已用服务异议另行核实 | 02、04 |
| 订单关系 | 已完成的 79 元体验独立，不扣新卡次数；再买卡新增付款 880 元 | 04 |
| 优惠 | 无两次套餐、无追溯转卡规则；不现场编折扣或赠品 | 02、03、04 |
| 其他 | 无强制产品、无自动续费、无跨店通用安排 | 02、03、04 |
| 照片 | 自愿、不另收费；可只做文字；记录不构成诊断或效果证明 | 01、02、04 |

以下信息材料没有明确，必须标为待核实：真实空位、准确改约细则、退款到账时间、过期未用次数处理、有效期起算时点、具体用品/成分、节假日营业安排。不能将“可申请退回”扩写为“随时秒退”或“过期也无条件退”。

预算比较不代表建议服务频率，也不锁定未来价格。全按常规单次：n × 240。若 n 是 4 的倍数，全按四次卡：(n ÷ 4) × 880；否则应明确使用“整卡加剩余单次”的组合算法。每张卡的有效期和客户能否安排仍需单独判断。
